# Health Monitor Public Build Mirror

This repository exists only to run Apple CI using GitHub's public
hosted runners without paid Actions usage.

Canonical development repository: **bumssi12-ship-it/health-monitor** (private).

This public mirror contains source and build configuration only.
It must not contain runtime health databases, backups, logs, tokens,
certificates, provisioning profiles, .env files, or private keys.

Do not place personal health data in this repository.
