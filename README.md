# Health Monitor V17 — One Click

V17 is the current canonical package.

On Windows:
1. Extract `HealthMonitorV17_OneClick.zip`.
2. Double-click `START.cmd`.

The launcher validates the package, safely creates/updates the private
`health-monitor` GitHub repository, starts the manual macOS-26 build, and
collects diagnostics automatically.

Application behavior remains based on V16 Safety & Quality. Feature expansion
is intentionally frozen until the first real Apple SDK build passes.

See `AUDIT_V17.md` and `WINDOWS_ONE_CLICK.txt`.
