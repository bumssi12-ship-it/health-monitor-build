Health Monitor V17 - Windows One Click
======================================

사용법은 2단계뿐입니다.

1. HealthMonitorV17_OneClick.zip 을 "압축 풀기" 합니다.
2. 풀린 폴더 안의 START.cmd 를 더블클릭합니다.

이전처럼:
- 앱 ZIP 따로 두기
- START 파일과 ZIP 위치 맞추기
- FIX ZIP 실행하기
- Publisher 수동 수정하기
는 필요 없습니다.

START.cmd가 자동으로 수행합니다:
- Windows PowerShell 스크립트 구문/호환성 검사
- SHA-256 소스 무결성 검사
- Git / GitHub CLI 확인
- 필요한 경우 GitHub 로그인
- private health-monitor 저장소 생성 또는 안전한 갱신
- 소스 commit/push
- GitHub macOS-26 빌드 시작
- iOS/watchOS Xcode build 감시
- 성공/실패 로그 자동 수집
- GitHub Actions artifact 자동 다운로드 시도
- LAST_BUILD_STATUS.txt 생성

실제 iPhone/Apple Watch 설치는 Apple SDK cloud build가 통과한 뒤 진행합니다.
